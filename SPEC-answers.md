# ТЗ: экран «Ответы клиентам»

## Цель экрана

Дать исполнителю услуг понятный контроль над тем, на какие вопросы AI-агент
может отвечать клиентам и из каких источников брать подтверждённые данные.

## 1. Заголовок

- Заголовок: «На какие вопросы отвечает агент».
- Подзаголовок: «Выберите темы, по которым агент сможет консультировать
  клиентов от вашего имени».
- Блок выбора режима работы отсутствует.

Компоненты AKITA: `H1`, `P`.

## 2. Базовый набор тем

Блок всегда отображается на экране. В нём три преднастроенные темы:

1. Консультация по цене.
   Источники: «Цена из объявления», «Цена из прайс-листа».
2. Загруженность графика.
   Источник: «График исполнителя».
3. Вопросы об услуге.
   Источники: «Объявление», «Описание услуги».

Каждая строка содержит:

- переключатель включения темы;
- название;
- краткое пояснение;
- подпись «Источник данных»;
- один или несколько источников.

В заголовке блока отображается счётчик включённых тем.

Компоненты AKITA: `H2`, `H3`, `P`, `Span`, `Switcher`.

## 3. Расширенный набор тем

Под базовым набором находится отдельный блок:

- заголовок «Расширенный набор тем»;
- пояснение «Добавьте вопросы, которые важны именно для вашей услуги»;
- кнопка «Выбрать тему»;
- пустое состояние «Дополнительных тем пока нет», пока пользователь ничего
  не добавил.

Компоненты AKITA: `H2`, `P`, `Button`.

## 4. Окно добавления темы

По кнопке «Выбрать тему» открывается модальное окно «Добавить тему».

Поля:

1. «Тема вопроса».
   Placeholder: «Например, район выезда».
2. «Источник данных».
   Placeholder: «Например, описание услуги или мой прайс-лист».
3. Переключатель «Включить тему сразу».
   По умолчанию включён. Если выключен, тема добавляется как неактивная.

Кнопки:

- «Отмена» — закрывает окно без сохранения;
- «Добавить тему» — недоступна, пока оба текстовых поля не заполнены.

Закрытие возможно по крестику, кнопке «Отмена» и клику на оверлей.

Компоненты AKITA: `Modal`, `Modal.Header`, `Modal.Content`, `Modal.Footer`,
`Input`, `Switcher`, `Button`, `Span`, `P`.

## 5. Добавленная тема

После сохранения тема появляется в расширенном наборе и содержит:

- переключатель активности;
- введённое название;
- метку «Добавлено вручную»;
- введённый источник данных.

Переключатель можно менять без удаления темы.

## 6. Сохранение экрана

Нижняя кнопка «Сохранить настройки» сохраняет состояние базовых и
расширенных тем. До нажатия показывается текст «Изменения сохранятся после
подтверждения», после нажатия — краткое подтверждение «Настройки сохранены».

Компоненты AKITA: `Button`, `P`.
